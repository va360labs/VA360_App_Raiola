## Acceptance Criteria

| AC | Descripción | Estado |
|----|-------------|--------|
| AC-01 | [AC-01] [JR-F1.1] Cuando llega la petición de verificación de WhatsApp Cloud API con el token de verificación configurado, el webhook responde con el valor de `hub.challenge`; con un token distinto responde con estado 403. | PASS |
| AC-02 | [AC-02] [JR-F1.1] Cuando llega un mensaje de texto con el formato de WhatsApp Cloud API, el webhook responde con estado 200 en menos de 2 segundos y el mensaje aparece en la bandeja con canal WhatsApp, número, nombre del contacto, texto y hora de recepción. | PASS |
| AC-03 | [AC-03] [JR-F1.2] Si el mismo mensaje (mismo identificador de WhatsApp) llega dos veces, la bandeja muestra una sola entrada. | PASS |
| AC-04 | [AC-04] [JE-F1.1] Si la instalación tiene activada la verificación de firma de WhatsApp y la firma de la petición no coincide, el webhook responde con estado 401 y no guarda el mensaje. | PASS |
| AC-05 | [AC-05] [JR-F1.4] Cuando llega un mensaje que no es de texto (imagen, audio, documento), aparece en la bandeja con la nota «Tipo de mensaje no soportado» y en estado «Requiere revisión». | PASS |
